# Asala Hub — Day 1 Scaffold

Asala Hub is an offline-first e-learning PWA. This is the Day 1 Sprint 1 skeleton setup containing a Dockerized PostgreSQL database, FastAPI backend (SQLModel + Alembic), and Next.js frontend.

## Prerequisites

Before starting, make sure you have the following installed:
- [Docker](https://www.docker.com/products/docker-desktop/) (Docker Desktop recommended)
- [Docker Compose](https://docs.docker.com/compose/install/)

---

## Getting Started

Follow these steps to initialize and start the local development stack.

### 1. Configure Environment Variables
Copy the `.env.example` file to create your local `.env` configuration:
```bash
cp .env.example .env
```
*(By default, this is pre-configured to point to the local containers).*

### 2. Start the Docker Services
Bring the entire stack up using Docker Compose:
```bash
docker compose up --build
```
This starts three services:
- **Database (`db`)**: PostgreSQL 16 Alpine, running on port `5432`
- **Backend (`backend`)**: FastAPI, running on port `8000` (with Uvicorn hot-reload)
- **Frontend (`frontend`)**: Next.js (App Router), running on port `3000` (with Tailwind CSS and hot-reload)

---

## Running Database Migrations

Database tables are managed using SQLModel and Alembic. Once the containers are running and the database is healthy, apply the migrations inside the backend container.

### Generate Initial Migration
*(Note: An initial migration script will be autogenerated and applied as part of the Day 1 done criteria).*
To create a new migration from changes to the model files:
```bash
docker compose exec backend alembic revision --autogenerate -m "description_of_changes"
```

### Apply Migrations to Database
To run all pending migrations and update your database schema to the latest version:
```bash
docker compose exec backend alembic upgrade head
```

### Check Database Tables Structure
To verify the tables inside PostgreSQL, run `psql` within the database container:
```bash
docker compose exec db psql -U postgres -d asala_db -c "\dt"
```
You should see all 6 schema tables listed:
- `users`
- `courses`
- `modules`
- `assignments`
- `submissions`
- `transaction_logs`

## Architecture Overview

- **Frontend**: Next.js App Router, using Tailwind CSS and TypeScript. Exposes health status visualizer connected to the backend.
- **Backend**: FastAPI app with CORS configured for `http://localhost:3000`. Employs database session dependencies mapped to Postgres.
- **Database**: PostgreSQL 16 Alpine, persistent database volume named `postgres_data`.
